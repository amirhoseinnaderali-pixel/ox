# Research positioning

VEPO-LLM belongs to an existing research area rather than claiming that the repository itself establishes a new paradigm.

Related work includes:
- Fan et al., Automated Repair of Programs from Large Language Models (2022): https://arxiv.org/abs/2205.10583
- Peng et al., PerfCodeGen (2024): https://arxiv.org/abs/2412.03578
- Farzandway and Ghassemi, Automated Repair of C with Large Language Models (2025): https://arxiv.org/abs/2509.01947
- Cheng et al., PracRepair (2026): https://arxiv.org/abs/2606.17612

The repository implements proposal generation, objective execution feedback, correctness gating, performance measurement, acceptance policies, ablations, result schemas, and reproducibility tooling.

A publishable contribution would require empirical evidence showing a meaningful effect of some combination of iterative search, execution verification, acceptance strategy, or budget allocation. The repository does not currently establish novelty, state-of-the-art performance, universal model superiority, or global optimality.

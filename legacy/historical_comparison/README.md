# Historical comparison archive

This directory preserves the original OX/Claude/Grok exploratory comparison, including model-specific source files, comparison scripts, and result JSON files.

Historical claims are not adopted as VEPO-LLM findings. The old benchmark used tiny workloads and single-run-style timing measurements. The archived material is retained so a researcher can inspect exactly what was previously done.

The manually engineered OX source files are duplicated under benchmarks/reference_implementations/ for controlled reference-baseline experiments.
